# CDAWG Mascot Canonical Package V1

These four files are the approved inputs for Cdawg Arcade Mascot Production Phase 1.

## Authority order

1. `cdawg-mascot-turnaround-v1.png` — anatomy, proportions, markings, collar, and tag
2. `cdawg-mascot-expressions-v1.png` — facial performance and personality
3. `cdawg-mascot-movement-v1.png` — pose language and motion character
4. `CDAWG_MASCOT_3D_PRODUCTION_SPEC_V1.md` — modeling, rigging, animation, export, and validation requirements

The canonical base mascot wears only the orange collar and circular `C` tag. The wardrobe comparison and all rejected concepts are intentionally excluded.

These images are concept references, not finished 3D assets or production sprites.
