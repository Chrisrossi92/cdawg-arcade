# CDAWG Arcade Brand Direction Package V1

This package contains the approved visual direction for the CDAWG Arcade production brand system.

- Start with `CDAWG_ARCADE_BRAND_DIRECTION_V1.md`.
- Treat the PNG boards as references only.
- The selected standalone mark is **Option 2 — Notched Tag**.
- Do not ship cropped or traced raster elements from the boards as final logos or interface assets.
- Build final logos as deterministic SVG artwork and the Arcade interface in code.
